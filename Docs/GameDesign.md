# The World — 게임 기획

작성일: 2026-10-26  
상태: 초기 구상 정리. 게임 기능은 아직 구현하지 않았다.

## 기본 콘셉트

하나의 도시에 NPC 주민들이 스스로 판단하며 살아가는 인간 시뮬레이션 게임이다. 플레이어는 원하는 주민을 만들어 세계에 추가하고, NPC에게 행동을 지정하며 해당 주민의 세부 정보를 확인한다.

플레이어는 특정 캐릭터를 직접 조작하지 않는다. 세계를 바라보면서 주민 생성과 행동 지정을 통해 참여한다.

## 확정된 내용

| 항목 | 기획 내용 |
| --- | --- |
| 세계 | 도시 하나를 기본 무대로 한다. |
| 주민 | 도시 안에 NPC들이 존재한다. |
| 자율 생활 | NPC는 플레이어의 지시가 없어도 스스로 판단하고 행동한다. |
| 핵심 체험 | 주민들이 실제 사람처럼 각자의 삶을 살아간다고 느끼게 한다. |
| 주민 생성 | 플레이어가 원하는 주민을 만들 수 있다. |
| 세계에 추가 | 생성한 주민을 세계에 추가할 수 있다. |
| 조작 방식 | 캐릭터를 직접 조작하지 않고 NPC에게 수행할 행동을 지정한다. |
| 지시 이행 | 플레이어가 지정한 행동은 NPC가 반드시 수행한다. 자율 판단보다 플레이어의 지시를 우선하며 거절하지 않는다. |
| 선택된 NPC | NPC를 골라 행동을 선택한 순간, 해당 캐릭터가 선택된 NPC가 된다. |
| 세부 정보 | 행동을 선택한 시점에 해당 NPC의 세부 정보를 확인할 수 있다. |

주민을 만들 때 설정할 수 있는 항목과 세부 정보 화면에 표시할 항목은 아직 정하지 않았다.

## 핵심 방향: 사람처럼 살아가는 NPC

플레이어가 지시하지 않는 동안에도 주민들의 생활이 이어지는 것을 게임의 중심으로 삼는다. 선택되지 않은 NPC도 도시 안에서 살아간다. NPC 선택은 해당 주민에게 개입하고 세부 정보를 확인하는 상태다.

이 방향을 구체화하기 위한 행동 설계 초안은 다음과 같다. 아래 시스템의 세부 채택 여부와 범위는 추가 기획에서 정한다.

| 시스템 후보 | 행동에 반영할 내용 | 플레이어가 관찰할 수 있는 차이의 예 |
| --- | --- | --- |
| 현재 상태와 욕구 | 배고픔, 피로, 기분, 소지금 등 | 같은 식사 기회라도 급하게 먹거나 돈을 아끼기로 결정 |
| 성격과 선호 | 사교성, 신중함, 취향 등 | 같은 모임에 참여하거나 혼자 시간을 보내기로 결정 |
| 개인 목표 | 당장 할 일과 장기적으로 원하는 일 | 쉬고 싶어도 약속이나 목표 때문에 다른 행동을 선택 |
| 경험과 기억 | 이전 행동의 결과와 겪었던 사건 | 과거에 불편했던 장소나 사람을 다음 선택에서 고려 |
| 대인 관계 | 상대에 대한 친밀감, 신뢰 등 | 같은 부탁에도 상대에 따라 다르게 반응 |

판단의 흐름은 **상황을 인지하고 → 자신의 상태와 기준으로 행동을 선택하고 → 실행 결과를 이후 판단에 반영하는 것**을 제안한다.

예를 들어 배가 고픈 두 주민이 있더라도 한 명은 친구와 식사를 하고, 다른 한 명은 돈을 아끼려고 집으로 돌아갈 수 있다. 이후 친구와의 관계나 남은 돈이 다음 행동에 영향을 주는 식이다. 이 예시는 행동 설계의 방향을 설명하기 위한 것이며 식당, 경제, 관계 시스템의 구현 범위를 확정하는 것은 아니다.

행동의 이유를 플레이어가 이해할 수 있게 만드는 것도 설계 목표로 제안한다. 선택된 NPC의 세부 정보에 현재 상태와 함께 ‘왜 지금 이 행동을 하는지’를 보여주는 방안을 검토한다. 표시 항목은 아직 미정이다.

## 플레이어 지시와 자율 행동의 관계

- 플레이어의 지시가 없을 때는 NPC가 스스로 판단하며 생활한다.
- 플레이어가 행동을 지정하면 NPC는 해당 행동을 반드시 수행한다.
- 성격, 기분, 선호 등은 플레이어의 지시를 거절하거나 다른 행동으로 임의 교체하는 근거가 되지 않는다.
- NPC가 스스로 선택한 행동보다 플레이어가 지정한 행동을 우선한다. 기존 행동을 언제 중단하고 지시 행동을 시작할지에 대한 세부 규칙은 아직 정하지 않았다.

행동을 지정하는 순간 해당 주민이 선택된 NPC가 되고 세부 정보를 확인할 수 있다는 기존 규칙도 유지한다.

## 플레이 흐름

1. NPC들이 존재하는 도시를 바라본다.
2. 원할 때 주민을 생성하고 세계에 추가한다.
3. 행동을 시키고 싶은 NPC를 고른다.
4. 해당 NPC에게 시킬 행동을 선택한다.
5. 그 순간 해당 NPC가 **선택된 NPC**가 되며, 세부 정보를 확인할 수 있다.

주민 생성과 추가는 필요할 때 사용하는 기능이다. NPC에게 행동을 지정할 때마다 주민을 새로 만드는 것은 아니다.

## NPC 선택과 정보 표시

이 기획에서 확인된 정보 표시 시점은 **행동을 선택한 순간**이다. 행동 완료 후에 정보를 확인하는 흐름으로 설계하지 않는다.

NPC를 고르는 입력과 행동을 지정하는 입력을 화면에서 어떻게 구분할지는 후속 UI 기획에서 정한다. 단순히 NPC를 클릭했을 때 보이는 정보 범위도 아직 미정이다.

선택된 NPC가 있다는 것은 현재 살펴보는 주민이 정해졌다는 뜻이다. 캐릭터를 직접 조작하는 모드로 전환되는 것은 아니다.

한 번 확인한 정보가 선택 해제 후에도 계속 공개되는지, 여러 NPC를 동시에 선택할 수 있는지는 아직 정하지 않았다.

## 다음에 정할 사항

| 주제 | 결정할 내용 |
| --- | --- |
| 자율 행동 설계 | 판단에 사용할 상태와 성향, 행동 우선순위, 경험의 반영 범위 |
| 행동 지시 | 가능한 행동 종류, 실행 시점과 기존 행동의 중단 방식, 플레이어에 의한 취소와 교체 |
| 주민 생성 | 플레이어가 정하는 항목과 자동으로 생성되는 항목 |
| 세부 정보 | 표시할 정보의 종류와 선택 전후의 표시 범위 |
| 선택 유지 | 선택 해제와 전환 방식, 동시 선택 가능 인원 |
| 도시 | 배경과 시대, 초기 규모, 건물과 시설, 도시 편집 가능 여부 |
| 플레이 목표 | 플레이어가 추구할 목표와 자유롭게 관찰할 수 있는 범위 |

첫 시제품의 도시 규모와 주민 수, 포함할 행동 및 시스템 범위는 아직 정하지 않았다.
